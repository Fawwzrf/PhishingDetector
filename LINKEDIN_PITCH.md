**Post Content:**

Saya baru saja menyelesaikan proyek hobi yang cukup menantang: **PhishingDetector** — sebuah sistem AI end-to-end untuk mendeteksi website penipuan secara real-time.

Masalah terbesar pada detektor phishing tradisional adalah **Bias**. Model seringkali menghukum URL yang panjang hanya karena "terlihat mencurigakan", padahal banyak situs e-commerce sah (seperti Tokopedia atau Amazon) memiliki struktur URL yang kompleks.

**Apa yang saya lakukan untuk mengatasinya?**
✅ **Anti-Bias Engine**: Menggunakan teknik *Feature Blindness* untuk memfokuskan model pada integritas domain daripada kompleksitas path. Hasilnya? Akurasi pada URL kompleks naik dari 0% ke 90%!
✅ **Explainable AI (XAI)**: Mengintegrasikan **SHAP** untuk memberikan transparansi penuh. Sekarang kita tahu *mengapa* AI menganggap sebuah link berbahaya.
✅ **Full-Stack Implementation**: Dibangun dengan FastAPI di backend dan Next.js 15 (React 19) di frontend untuk pengalaman pengguna yang mulus.

**Tech Stack:**
🐍 Python / FastAPI / LightGBM
📈 Optuna / SHAP / MLflow
⚛️ Next.js 15 / Tailwind CSS v4
