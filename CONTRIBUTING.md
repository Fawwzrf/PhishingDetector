# Contributing to PhishingDetector

Terima kasih telah tertarik untuk berkontribusi! Saya sangat menghargai bantuan Anda untuk membuat proyek ini menjadi lebih baik.

## Cara Berkontribusi

1. **Fork** repository ini.
2. Buat **Branch** baru untuk fitur atau perbaikan bug (`git checkout -b feature/nama-fitur`).
3. Lakukan **Commit** perubahan Anda dengan pesan yang jelas.
4. **Push** ke branch Anda (`git push origin feature/nama-fitur`).
5. Buat **Pull Request**.

## Aturan Main

- Pastikan kode Anda mengikuti gaya penulisan yang sudah ada.
- Sertakan komentar yang jelas untuk logika yang kompleks.
- Jika Anda menambahkan fitur baru, harap sertakan unit test jika memungkinkan.

# Contributing to PhishingDetector (English)

Thank you for your interest in contributing! I truly appreciate your help in making this project better.

## How to Contribute

1. **Fork** this repository.
2. Create a new **Branch** for your feature or bug fix (`git checkout -b feature/feature-name`).
3. **Commit** your changes with a descriptive message.
4. **Push** to your branch (`git push origin feature/feature-name`).
5. Open a **Pull Request**.

## Guidelines

- Ensure your code follows the existing style.
- Include clear comments for complex logic.
- If you add a new feature, please include unit tests if possible.
